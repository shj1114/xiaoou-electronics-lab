# 小欧实训室

适配手机的《电子产品装调》课程网页：毫欧电阻分选仪的制作与调试。

- [打开《电子产品装调》课程知识库](knowledge.html)：收录41个知识点，电脑端分栏阅读，手机端支持目录抽屉、搜索、收藏、笔记、原图放大和交互自测。
- 直接打开 [使用说明](使用说明.md) 查看课程功能、部署与在线AI设置。
- 项目文件可在本机双击“启动小欧实训室.cmd”运行。
- 所有访客都可使用课程问答、中文讲解音频、资料、图纸及互动实训。
- 独立课程知识库涵盖电学基础、元器件、识图、焊接工艺、测量仪器和项目调试。
- DeepSeek 在线问答按访客各自配置；密钥仅在访客当前页面内存中使用，刷新后清除；API 费用由各自 DeepSeek 账户承担。

原报告在网站副本中去除 Word 作者/编辑者属性，保留可见正文、表格与图纸。课程仿真内容明确标注，不当作真实测量。
