# 小欧实训室

课程：《电子产品装调》  
项目：毫欧电阻分选仪的制作与调试

## 公网访问

本网页适配手机和桌面浏览器，发布到 GitHub Pages 后，任何人均可通过 HTTPS 网址直接访问课程问答、全部中文课程讲解音频、资料库、报告和图纸、双板元器件清单、学习笔记、随堂测验及互动实训。无需安装应用，也不需要登录 GitHub。

另有独立的[《电子产品装调》领域化知识库](knowledge.html)，按课程模块分栏组织 41 个知识点，包含目录搜索、原理/工艺/排故内容、收藏、笔记、计算器与自测；手机端可展开目录。

课程知识库问答、音频、图纸和互动实训开箱即用。需要 DeepSeek 开放式AI回答时，每位访客在“设置 → 连接DeepSeek”中填写自己的 API Key 并选择模型。密钥只存于该访客当前打开网页的内存中，刷新或关闭后自动清除，不写入公开仓库或浏览器存储。该访客的聊天内容会直接通过 HTTPS 发给 DeepSeek 处理，相关 API 费用由该访客自己的 DeepSeek 账户承担。网站所有者不提供或代付访客的 AI 额度。切回课程知识库随时可用。

## 在本地预览

Windows 双击“启动小欧实训室.cmd”，浏览器会打开 http://127.0.0.1:8765。保持服务窗口运行，即可使用本地模式的 DeepSeek 转接。无需安装其他 Python 依赖。

也可直接双击 `index.html` 使用课程知识库、六节内置音频、资料库、互动实训和自测。浏览器限制可能会阻止 `file://` 页面访问麦克风或在线 DeepSeek；请使用 HTTPS 公网网址或本地启动器。公共网站上的每位访客则使用本机浏览器安全模式直接连接。

## 公网 DeepSeek 使用方法

1. 访客在 DeepSeek 平台创建自己的 API Key。
2. 在手机 HTTPS 页面右上角打开设置，点“连接 DeepSeek”。
3. 输入该访客自己的 API Key，选择 `deepseek-flash`（快速学习）或 `deepseek-v4-pro`（深入分析），点击“验证并连接”。
4. 返回智慧问答开始提问。离开当前页面后再访问，需要重新输入密钥。

DeepSeek 官方接口、模型和费用可能变化，具体情况以 [官方接口文档](https://api-docs.deepseek.com/api/create-chat-completion) 和 [官方价格页面](https://api-docs.deepseek.com/quick_start/pricing) 为准。在线回答会把用户问题和相关课程资料发送给 DeepSeek；访客可在自己的设备上切回课程知识库。

不应把 API Key 提交到网站、公开仓库、聊天、截图或课堂演示里。若需要所有访客共用网站所有者付费的 AI Key，需另行部署有访问控制、额度限制和密钥管理的服务端，本 GitHub Pages 网站不会共享个人密钥。

## 功能一览

- **智慧问答**：24 份课程资料分类检索、DeepSeek 在线问答、来源跳转、复制与朗读、中文语音输入、示例问题。
- **数字人讲解**：原创电路精灵“小欧”，六节中文录音，点击互动、播放／暂停、章节选择、进度、倍速和讲解文稿。
- **资料获取**：完整项目报告和双板元器件清单、三张原图、两份官方离线数据手册、外部官方资料链接、搜索与收藏、CSV 下载。
- **互动实训**：两线和四线理想测量比较、引线误差、阈值分选、低音量提示和 CSV 导出。数据均标为教学仿真。
- **学习记录**：六题自测、即时讲解、实训笔记与导出、实测空白记录表。

## 依据与内容准确性

课程内容依据提供的实验项目设计报告。网文与 Word 下载版保留报告可见正文、表格和附图。网页使用的 DOCX 下载副本移除了 Word 文件属性中的作者／最后编辑者个人元数据，不修改正文内容；用户原始文件不会被改动。

报告对模拟表头与 ICL7107 数字显示的描述存在不一致，页面明确提示以实际板卡和图纸为准。报告中的设计参数和验收指标不是实测数据；100 mΩ 是量程中点，单点校准不能验证全量程。页面互动仪表使用理想教学模型，不代替真实硬件测试。

外部器件和测量参考来自 Tektronix/Keithley、Texas Instruments 与 Renesas 官方资料。项目原始报告电路图、中文课程音频、角色图片与代码资源在网站文件中本地提供。

## 手机与微信

这是发布到 HTTPS 的响应式 HTML 教学网站，手机微信浏览器可以直接打开，具有小程序式的竖屏导航。它不是微信平台内独立审核发布的小程序。麦克风识别、浏览器语音和下载的支持会依微信版本和设备而异；六节课程讲解使用内置音频，不依赖浏览器语音合成。

进度、笔记、收藏、问答记录和仿真记录保存在各访客自己的浏览器中。清除站点数据会删除这些内容，可使用页面提供的导出功能自行备份。

## 修改并重新发布

修改网页文件后，将相应更新提交至 GitHub 公共仓库 `main` 分支。首次发布需在仓库 **Settings → Pages** 中选择 **Deploy from a branch**、`main` 分支和仓库根目录。GitHub Pages 更新后，任何访客都可通过该 HTTPS 网址访问。
