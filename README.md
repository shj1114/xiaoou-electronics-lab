# 小欧实训室

《电子产品装调》课程项目：**毫欧电阻分选仪的制作与调试**。

## 手机网页版

[打开小欧实训室](https://shj1114.github.io/xiaoou-electronics-lab/)

手机浏览器或微信内置浏览器均可打开，无需安装，也无需登录 GitHub。

## 课程知识库

[打开《电子产品装调》领域化知识库](https://shj1114.github.io/xiaoou-electronics-lab/knowledge.html)

收录 41 个知识点，涵盖课程导学、电学基础、元器件与识图、装配焊接、测量仪器、项目调试与排故。支持搜索、分类目录、收藏、学习笔记、公式计算、自测和原始图纸放大。项目报告内容注明来源；新增基础知识作为课程补充。

## 实训室功能

- 智慧问答：内置课程知识库可直接使用；DeepSeek 开放式 AI 由访客自行填写 API Key，密钥只保存在当前页面内存中，费用由其自己的 DeepSeek 账户承担。
- 数字人讲解：原创电路精灵小欧，含六节中文语音讲解和播放进度控制。
- 资料获取：项目报告、图纸、器件手册与分类检索。
- 互动实训：两线与四线测量仿真、阈值分选、自测、笔记与收藏。

学习进度、笔记和收藏保存在各自设备的浏览器中。互动仿真用于教学，不代表真实硬件测量。
